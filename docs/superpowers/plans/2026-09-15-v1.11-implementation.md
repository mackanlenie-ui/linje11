# Mina arbetspass 1.11 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Leverera 1.11 med stabil datalagring, veckonavigering, kopiera-vecka och gemensamt ledig kväll.

**Architecture:** Lägg stabil lagring i `AppPrefs` och låt `MainActivityCurrent.getPreferences()` samt `Reminders` använda den, så befintlig kod migreras utan en stor omskrivning. Lägg ren beräkningslogik i `ScheduleInsights` och ny UI-logik i `MainActivityV111` ovanpå 1.10.

**Tech Stack:** Android Java, SharedPreferences, JUnit 4, Gradle 8.9, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-15-v1.11-design.md`

## Global Constraints

- `applicationId` ska fortsätta vara `se.minaarbetspass`.
- Samma permanenta releasecertifikat som 1.9.1 och 1.10 ska användas.
- Befintlig lokal data får inte skrivas över av migrationen.
- Lenies pass ska fortsatt sakna arbetspåminnelser.
