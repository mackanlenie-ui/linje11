# Mina arbetspass

En svensk Android-app för timanställda som vill hålla reda på arbetspass och arbetade timmar.

## Funktioner
- Lägg till datum, starttid, sluttid och rast
- Tjänstenummer, linje/omlopp och anteckning
- Flera pass samma dag (delade pass)
- Kalender och lista
- Summering per vecka och månad
- Redigera, kopiera och radera
- Säkerhetskopiera och återställ JSON
- Offline och anpassad för mobil/DeX

APK byggs automatiskt av GitHub Actions.
