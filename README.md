# Mina arbetspass

En svensk Android-app för att hålla reda på egna arbetspass och samtidigt kunna ha Lenies schema som separat översikt.

## Funktioner
- Lägg till datum, starttid, sluttid och rast
- Tjänstenummer, linje/omlopp och anteckning
- Flera pass samma dag (delade pass)
- Kalender och lista
- Summering per vecka och månad
- Redigera, kopiera och radera
- Säkerhetskopiera och återställ JSON
- Offline och anpassad för mobil/DeX

## Nytt i 1.8
- Egen startsida för Lenies schema
- Visar om Lenie jobbar nu, senare idag eller är ledig
- Nästa pass för Lenie visas tydligt
- Lenies månad visar antal pass och totala timmar
- Lila markeringar skiljer Lenies pass från dina
- Gemensam vy visar bådas schema tydligare
- Kalendern följer valt schema korrekt
- Lenies pass är rena översiktspass utan arbetad-status eller påminnelser

APK byggs automatiskt av GitHub Actions.
