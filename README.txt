Linje 11 GPS – Gävle

Ny separat Android-app med eget paketnamn: se.linje11.gps

Funktion:
- Knapp för Södra Åbyggeby -> Gävle Centrum
- Knapp för Gävle Centrum -> Södra Åbyggeby
- Öppnar Google Maps med hållplatserna i rätt ordning.

Bygg i Android Studio eller GitHub Actions på samma sätt som tidigare projekt.
